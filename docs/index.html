Overview

Strip identifiers and spec tokens for idempotent workflows. Built as a tiny zero-dependency Node toolkit with a library API and a stdin-friendly CLI.

Usage

git clone https://github.com/theworker02/stripspec.git
cd stripspec
node src/cli.js --help
node --test
